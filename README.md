# AVR Assembler Hex Disassembler

Простой дизассемблер для декодирования hex кода программ, написанных на Atmel AVR ассемблере. Проект преобразует Intel HEX формат (стандартный формат для микроконтроллеров) в читаемые AVR инструкции.

## Описание

Дизассемблер парсит hex пакеты в формате Intel HEX и преобразует их в соответствующие инструкции AVR ассемблера с поддержкой:

- Одно- и двухбайтовых команд
- Извлечения параметров команд (регистры, непосредственные значения, адреса)
- Корректного расчета адресов команд в памяти программы
- Работы с пакетами переменного размера

## Структура проекта

- `disassembler.py` — основной класс для парсинга hex кода
- `packet.py` — работа с Intel HEX пакетами
- `command_parser.py` — парсинг и извлечение параметров инструкций
- `instructions/` — определение набора поддерживаемых AVR инструкций
- `main.py` — пример использования
